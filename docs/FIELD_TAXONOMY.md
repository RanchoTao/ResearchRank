# Field taxonomy

Coarse labels provide interoperability, while fine topics define meaningful comparison cohorts. A topic may relate to multiple topics but has one primary parent in v0.

## Coarse fields

`cs.AI`, `cs.LG`, `cs.CV`, `cs.CL`, `cs.RO`, `cs.HC`, `cs.IR`, `cs.DB`, `cs.DC`, `cs.CR`, `cs.NE`, `stat.ML`, `math.OC`, `eess.IV`, `eess.AS`.

## Initial fine topics

- Efficient LLM Inference; Efficient VLM Inference; Model Compression; Quantization; KV Cache Optimization
- Long-Context Modeling; Streaming Language Models; Streaming Vision-Language Models
- Video Understanding; Online Video Understanding
- Multimodal Foundation Models; Vision-Language Models
- Agent Systems; Research Agents; Tool-Use Agents
- ML Systems; Inference Serving
- AI for Science; Mechanistic Interpretability; LLM Alignment; Retrieval-Augmented Generation

The compact seed catalog merges some aliases (for example Efficient LLM/VLM Inference and Streaming VLM); this is an example, not a complete taxonomy.

## Governance

A proposed topic needs a definition, inclusion/exclusion criteria, parent, aliases, neighboring topics, and curator. Split topics when communities or evaluation norms materially diverge; merge only with migration aliases. Never infer comparable scores solely because two topics share a coarse field.
